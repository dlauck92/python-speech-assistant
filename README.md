# Python Speech Assistant

Python Speech Assistant is a Python-based voice assistant designed to interact with users through voice commands, providing a hands-free experience for various tasks.

## Features

- **Voice Recognition**: Utilizes speech recognition to interpret and process user commands.
- **Text-to-Speech**: Converts text responses into spoken words for seamless interaction.
- **Modular Design**: Easily extendable to include additional functionalities as needed.

## Installation

1. **Clone the Repository**:

   ```bash
   git clone https://github.com/dlauck92/python-speech-assistant.git
   cd python-speech-assistant
   ```


2. **Create and Activate a Virtual Environment**:

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```


3. **Install Dependencies**:

   ```bash
   pip install -r requirements.txt
   ```


## Usage

After installation, run the main script to start the voice assistant:


```bash
python main.py
```


The assistant will listen for voice commands and respond accordingly.
